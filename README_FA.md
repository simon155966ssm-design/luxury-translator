# مترجم لوکس — نسخه آزمایشی ۰٫۱٫۰

این پروژه یک اسکلت اولیه اندروید با رابط فارسی است که برای Redmi Note 11 / Android 11 آماده شده است.

## قابلیت فعلی
- صفحه اصلی فارسی و راست‌چین‌پذیر
- درخواست مجوز نمایش روی برنامه‌های دیگر
- نمایش یک دکمه شناور قابل جابه‌جایی روی برنامه‌ها
- روشن و خاموش کردن دکمه شناور از داخل برنامه

## هنوز پیاده‌سازی نشده
- گرفتن تصویر صفحه با رضایت کاربر (MediaProjection)
- OCR و استخراج متن
- اتصال به سرویس ترجمه و تبدیل خروجی به فارسی
- حالت آفلاین، تاریخچه و ترجمه مکالمه

## ساخت
پروژه را در Android Studio باز کنید و اجازه دهید Gradle Sync انجام شود. سپس از مسیر Build > Build Bundle(s) / APK(s) > Build APK(s) فایل APK بسازید.

تنظیمات پروژه: minSdk 23، targetSdk 28، Java source سازگار با Android Studio.
